# ElBruno.AI.Jev visual assets

Original teal-and-violet braces and branching-choice artwork on deep navy,
created for an **independent community .NET SDK for Jev AI**. This is not an
official Jev or Microsoft logo and does not imply affiliation or endorsement.
The names Jev AI and .NET are descriptive references, not claims to their
trademarks.

## Exact public design prompt and generation command

The string below is the exact prompt submitted in each attempt. This
PowerShell command reproduces the successful provider selection and options;
it relies on an already configured provider and does not include credentials
or endpoints:

```powershell
t2i doctor
t2i providers
New-Item -ItemType Directory -Path .\images -Force | Out-Null
$prompt = 'Create an original minimal geometric emblem for an independent typed-decision developer library. Two bold opposing curly-brace-like forms enclose a simple three-node branching choice path: one input connects to two choices, with one choice emphasized to suggest reliable selection. Use a clean balanced silhouette, thick rounded strokes, large negative spaces, and very few shapes so the symbol remains clear at 64 pixels. Flat vector-like design with crisp edges, teal #2DD4BF and soft violet #A78BFA on a perfectly uniform deep navy #0B1020 square background. Center the emblem within the middle 68 percent of the canvas, leaving generous equal padding on all sides. No gradients, shadows, texture, fine lines, decorative circuitry, mockups, lettering, words, numerals, watermarks, existing brand logos, or endorsement marks. A single emblem only, front view, 1024 by 1024 composition.'
t2i $prompt --provider foundry-gpt-image-25-flare --width 1024 --height 1024 --steps 30 --out .\images\jev-mark-1024.png
```

The `--steps 30` flag records the submitted command; its interpretation is
provider-specific. Image generation is non-deterministic, so retain the
checked-in master when only refreshing layout or typography. Do not
regenerate artwork in normal builds, CI, or releases. A new master requires
another visual review and may require adjusting the derivative crop.

## Recreating derivatives without an image-provider call

From the repository root on Windows, with PowerShell, `System.Drawing`,
**Segoe UI**, and **Segoe UI Semibold** installed:

```powershell
.\scripts\Generate-BrandDerivatives.ps1
```

The script makes no network calls, needs no additional packages, does not
change the master, and overwrites only the four derivative PNGs listed above.
It refuses substituted fonts or overflowing text and validates all five
assets' PNG signatures, dimensions, and the NuGet icon's size.

### Composition recipe

1. Preserve the original 1024 x 1024 master unchanged.
2. For derivatives, crop an 800 x 800 square starting at master coordinate
   `(112, 96)`, trimming excess padding while retaining the entire emblem.
3. Normalize only dark matte pixels whose red, green, and blue channels are
   each at most 48 to `#0B1020`. This removes generated background variation
   without redrawing the colored symbol.
4. Resize from that cropped master using high-quality bicubic interpolation
   to create the 128 px and 64 px icons. Never enlarge a small icon.
5. Compose the hero at 1600 x 900 with a 488 px emblem and 112 px text margins.
   Compose the social preview at 1280 x 640 with a 352 px emblem and 80 px text
   margins; essential content remains within a 64 px crop-safe inset.
6. Render `ElBruno.AI.Jev`, `Typed decisions for Jev AI`, `.NET 10`,
   `COMMUNITY SDK`, and `Independent community SDK` in Segoe UI/Semibold.
   All font sizes use pixels at 96 DPI; positions and sizes are fixed in the
   script. Keep the light title, muted supporting copy, and teal framework
   badge on their specified dark backgrounds.

Layout is deterministic. Font rasterization and PNG encoding can vary
between Windows/font versions; the published PNGs are the canonical visual
assets.
